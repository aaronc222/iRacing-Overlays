# Theme sources and attribution

These are overlay adaptations of editor/terminal palettes, not affiliated theme products.
Panel opacity and readable label colors are adapted for racing overlays. In particular,
Dracula and Monokai use brighter muted labels than editor comments. Current retains the
original Basic Lap Timer colors; its unused semantic accents follow the Nord palette.
